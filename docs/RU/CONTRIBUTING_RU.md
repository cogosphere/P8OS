# Участие в проекте P8OS

## Открытая когнитивная инфраструктура для автономных систем

Благодарим вас за интерес к проекту P8OS.

P8OS — открытая исследовательская и инженерная инициатива, посвящённая созданию инфраструктуры для следующего поколения автономных интеллектуальных систем.

Мы приветствуем участие разработчиков, исследователей, студентов, архитекторов, технических писателей и всех, кто разделяет цели проекта.

# Процесс внесения изменений

1. Создайте Issue, если планируются значительные изменения.
2. Обсудите предлагаемый подход.
3. Реализуйте изменения.
4. Создайте Pull Request.
5. Примите участие в обсуждении результатов проверки.

Крупные архитектурные изменения рекомендуется обсуждать до начала реализации.

* программных фреймворков;

Платформозависимые функции рекомендуется реализовывать через абстрактные интерфейсы и адаптеры.
