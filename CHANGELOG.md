# Changelog

All notable changes to the P8OS project will be documented in this file.

P8OS follows the principles of Semantic Versioning (SemVer) while recognizing that the project is currently in an active research and prototype phase.

Version numbers before **1.0.0** may include significant architectural changes.

---

# Version Categories

* **Added** – New features, modules or documentation.
* **Changed** – Improvements or modifications to existing functionality.
* **Deprecated** – Features planned for removal.
* **Removed** – Deleted functionality or obsolete components.
* **Fixed** – Bug fixes and corrections.
* **Security** – Security-related improvements.
